# Pin screw — print, file and thread

Marcus Wu's [3x printed-parts BOM](https://docs.google.com/spreadsheets/d/16EJePozXW-uC6UFISzyT2eMk7c8wh6v-EP5L1U8fzfM/edit)
lists one crank handle pin screw at 100% infill and 0.2 mm layer height.
It calls for filing its sides smooth and cutting the thread with an M4 die;
reversing the die may be needed to reach the full thread length.

The current model selects the original source-backed screw geometry. This
asset adds instructions and does not cut a thread into the model. Polymer
and actual printed mass remain unknown. Evidence inspected 2026-10-04.
