# Existing simulation fits — geometry provenance

The selected main crank is the existing `SeatedMainCrank` from
`simulation/crank_coupling_parts.py`, whose adjustment cuts a roof pocket
for the shaft tip. The handle is the existing `SeatedCrankGrip` from
`simulation/crank_grip_parts.py`. Both are simulation fit replacements,
not byte-identical author STL geometry. This production leaves those
model choices unchanged and exports their actual current artifacts as draft.

Marcus Wu's [3x printed-parts BOM](https://docs.google.com/spreadsheets/d/16EJePozXW-uC6UFISzyT2eMk7c8wh6v-EP5L1U8fzfM/edit)
lists one handle and one main crank, each with 40% infill, 0.2 mm layer
height, with support specified for the main crank. Those instructions are
source evidence, not installed proof for the fitted simulation replacements.
No polymer, density or measured mass is supplied. Evidence inspected 2026-10-04.
