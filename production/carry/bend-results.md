# Ten result carry springs — made-wire evidence

Marcus Wu's `Manual/Curta Build Manual.pdf`, printed page 30, describes
ten result carry levers and five turns carry levers. It specifies about
57 mm lengths of 0.6 mm music wire formed using the carry-spring bending
tool. The [hardware BOM](https://docs.google.com/spreadsheets/d/16EJePozXW-uC6UFISzyT2eMk7c8wh6v-EP5L1U8fzfM/edit#gid=1182246287)
also lists fifteen carry springs made using that wire and tool.

This instruction scopes ten actual mounted-spring subproductions. Their
flexible `wire` leaves remain unassigned: the framework's current process
vocabulary has no bent-wire process. They are not purchased finished springs.
The approximate blank length is not a measured finished length, supplier
pack quantity or mass. Source inspected 2026-10-04.
